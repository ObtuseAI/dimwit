## High-impact findings and repairs

### 1. Recursive improvement stopped at static queue generation — repaired

The autonomy matrix and game-builder scorecard ranked work, but no controller measured a candidate against a
validator baseline, learned from attempt history, quarantined regressions, or enforced a sweep-level cost/time
budget.

Added `dimwit/improvement.py` and the `dimwit.py improve` front door. The controller now:

1. ranks tasks lexicographically from current validator evidence;
2. binds per-asset evidence when a pipeline has multiple assets;
3. enforces task, cost, wall-clock, retry, and cooldown budgets;
4. executes one bounded experiment at a time;
5. reruns the authoritative validation suite after every candidate;
6. computes validator-level resolved/regressed/missing-evidence deltas;
7. withholds review eligibility on evaluation failure;
8. quarantines a regression and stops by policy;
9. persists attempt memory in a hash-chained ledger;
10. atomically writes the run artifact.

Plan-only is the default. Mutation requires an explicit `--execute`:

```powershell
python dimwit.py improve
python dimwit.py improve --execute --max-tasks 3 --max-cost 6
```

### 2. Director failure isolation and breaker granularity were unsafe — repaired

A single unhandled pipeline exception could abort the full sweep. Circuit breakers were keyed only by pipeline,
so one bad character could suppress every other character using the same pipeline.

The director now isolates execution exceptions, continues to the global gate, keys breakers by
`pipeline:asset`, discards unsafe legacy pipeline-wide breaker keys, and saves breaker state atomically.

### 3. MCP mutation boundary was bypassable — repaired

The in-process MCP server exposed generic capability dispatch, including `EXECUTE/ue.live`, while the Unreal
MCP server exposed arbitrary editor Python execution and level saves. Those surfaces bypassed the safer default
allowlist in the LLM agent loop.

Read-only tools remain enabled by default. Mutating MCP tools now require an explicit server-environment opt-in:

- `DIMWIT_MCP_ALLOW_MUTATION=1` for engine/capability mutation;
- `DIMWIT_UE_MCP_ALLOW_MUTATION=1` for live Unreal mutation;
- `DIMWIT_MCP_ALLOW_PAID_MODEL_CALLS=1` separately for calls that can incur provider usage.

The two gates are independent: tuning live lighting requires both mutation and paid-model authorization.

### 4. Default test discovery was broken — repaired

`python -m pytest` collected packaged repository copies under `artifacts/`, causing duplicate-module import
errors. `pytest.ini` now scopes discovery to the authoritative `tests/` and `dimwit/tests/` trees and excludes
artifact/package copies.

### 5. Self-measurement was stale and rejected — repaired

The full gate correctly rejected stale/fabricated-looking self-metrics. The real self-metrics pipeline was rerun
over the current full report; the targeted domain now passes 6/6.

### 6. Grapple socket contract was internally inconsistent — repaired

The Skyclaw was declared forearm-mounted but retained two `hand_l` runtime fallbacks. Those fallbacks were
removed in the adjacent WANEFALL source, with the honest constructor offset retained when `lowerarm_l` is
unavailable. Movement/traversal now passes 7/7.

## Next architecture frontier

Highest-leverage future work, in order:

1. Transaction manifests for every mutating pipeline: declared write set, preimage hashes, postimage hashes,
   and pipeline-owned rollback adapters. Regression quarantine is now safe, but rollback is not yet universal.
2. Replace machine-specific project constants with one validated workspace manifest and path capability probe.
3. Add an evaluation corpus for planning quality, tool selection, recovery, long-horizon completion, cost, and
   time-to-proof—not only artifact correctness.
4. Expand task coverage so maintenance actions such as optics calibration are first-class pipelines rather than
   manual commands, while preserving the paid-call gate.
5. Add deterministic simulation/fuzz campaigns for pipeline crashes, ledger corruption, stale evidence races,
   interrupted writes, and concurrent schedulers.
6. Add signed policy/config provenance so a local process cannot silently widen mutation authority or lower a
   budget outside operator review.

## Non-negotiable boundary

“Recursively improving” means evidence-driven experiments whose quality bars ratchet upward. It does not mean
unbounded self-modification, fabricated proof, silent payment, arbitrary editor execution, or autonomous
promotion past human review.
